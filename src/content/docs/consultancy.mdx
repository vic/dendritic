## Why Nix?

- **Reproducibility** — builds are deterministic, byte-for-byte identical across machines
- **Security** — every dependency is pinned by hash, eliminating supply-chain attacks
- **Rollbacks** — atomic system updates with instant rollback on failure
- **Multi-project** — developers work on multiple projects without dependency conflicts
- **Auditability** — the entire dependency graph is inspectable and verifiable
